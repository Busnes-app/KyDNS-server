# KyDNS UI Council

## Purpose

Own fresh synthetic KyDNS captures, independent ratings, provenance and progression evidence.

## Ownership

- Parent owns capture inputs, audits, comparison galleries and spreadsheet exports.
- Each reviewer owns only its assigned raw Markdown/JSON pair; preserve published bytes.

## Local Contracts

- Preserve DNS/admin authorization, routes, CSP, settings, named themes, saved choices and OS following.
- Use the pinned ky-suite-v2 authority in authority.json; quality and brand remain separate.
- Freeze every current per-file score vector and observation before prior/peer scores, historical quality images, parent audits or exports. Only own prior round is allowed after freeze for drift.
- Progression uses only Opus current-round overall quality, rounded half-up to one decimal;8.0 accepts. No peer/history/brand pooling or individual-cohort veto. Owner rejection reopens progression.
- Show all round scores and pending/unused reviewers. Gemini is advisory after both primaries approve; known exhausted quota is not retried or a progression blocker.
- Keep one left navigation region and shared Appearance picker; no adjacent content sidebar.

## Work Guidance

- Capture actual local administrator workflows using a disposable private fixture and real product setup/authentication. KyDNS is administrator-only; do not invent ordinary-user workflows.
- All listeners/upstreams stay loopback on owned unprivileged ports; disable DHCP. Never change host resolvers or use production data/services.
- Match1280×900 and390×844,DPR1,OSlight/dark,locale/timezone,initial viewport and saved-choice state across stages. Synthetic content/roles/conditions and source revisions are explicit.
- Use native T3 Computer Use first, then the documented capture driver for exact DPR. Preserve original images, manifests and raw reviews. Inspect every original individually; permit one bounded correction/confirmation per batch.
- After the owner-reported hard lock, local work is limited to targeted checks, a capped sequential Go build and one browser. Full required suites run in hosted CI; reuse persistent toolchain/dependency caches.
- Keep credentials, setup/API tokens, private keys and databases outside the repository in0700/0600 owned paths. No snapshots of filled or pending login/setup secrets.
- A screenshot score never passes complete behavior, accessibility, connected-service or production gates. Missing flows are explicitly unscored.

## Verification

- `python3 docs/ui-dns-eight/build-report.py --current-round N --pr URL` validates preserved review arithmetic/full-vector freezes against canonical inventories and regenerates the spreadsheet, CSV and round history. The XLSX writer reuses the Drive Council's stdlib exporter and checks XML/CRC/data round-trip; no package installation is required.
- Capture drivers own exact-DPR originals and their manifests. Preserve each driver and original batch; use distinct stage names for later captures. Review input inventories explicitly separate current quality, historical and brand-only images.
